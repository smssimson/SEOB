S:ARCH v143-r1 — 프로젝트 7 수정본

[화면에서 확인할 변화]
1. 공통: 현장 선택 → 층/도면 관리 → 작업 도구 순서로 화면 통일.
2. 공통: 주 작업 / 기타 도구 탭으로 도구를 정리. 기존 기능 유지.
3. 출력 영역: 프로젝트 공유 버튼으로 기기 공유 메뉴 호출. 지원하지 않는 기기는 JSON 다운로드.
4. 현장조사: 휴대폰에서 내보내기·공유·불러오기 버튼을 두 열로 정리.
5. 도면작성: 작업 영역 제목의 배경과 글자 대비 개선.
6. 자료 보호: 백업 파일 검사로 현재 자료를 바꾸지 않고 JSON 구조 확인.

[이번 추가 보완]
- 복구 기록이 전체 내용을 비교하도록 개선. 같은 길이의 중간 수정도 감지.
- /drawing/index.html 등 파일명을 포함한 주소에서도 복구 기능 작동.
- 복구 기록이 없으면 첫 기록 저장 방법 안내.
- 복구 목록 안내의 줄바꿈 수정.
- 오프라인 캐시 갱신.
