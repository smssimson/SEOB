SMETRIC v60 - 오프라인 현장 사용 지원

적용: 홈 + 현장조사/도면작성/장비조사/기울기
설치: 기존 자동배포 방식으로 ZIP 업로드.
중요: 업로드 후 인터넷 연결 상태에서 SMETRIC 홈 및 네 프로그램을 각각 한 번 실행하고, 화면을 닫았다가 다시 열어 주세요. 오프라인 캐시 설치가 끝난 다음 비행기 모드에서 홈과 각 프로그램을 시험해 주세요.
PDF.js는 외부 CDN에 연결되는 경우 최초 온라인 실행 중 추가 캐시를 시도합니다. CDN 접근 실패 시 PDF 가져오기는 오프라인에서 제한될 수 있습니다. 이 ZIP에는 PDF.js 라이브러리 원본이 포함되지 않습니다.
현장 데이터는 브라우저 내부 저장소에 저장되므로 기기/브라우저 데이터 삭제, 비공개 모드, 저장공간 부족에 주의하세요. JSON 백업을 권장합니다.
오프라인 작업은 서버로 동기화되지 않습니다. 기존 자료 저장 구조를 변경하지 않았습니다.
