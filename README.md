# S:ARCH — 건축 현장업무 플랫폼

건축 시설물의 **현장조사 · 도면작성 · 장비조사 · 기울기 조사**를 태블릿과 PC에서 수행하기 위한 웹 기반 PWA입니다.

**[S:ARCH 실행](https://smssimson.github.io/SEOB/)** · [현장조사](https://smssimson.github.io/SEOB/survey/) · [도면작성](https://smssimson.github.io/SEOB/drawing/) · [장비조사](https://smssimson.github.io/SEOB/schmidt/) · [기울기](https://smssimson.github.io/SEOB/tilt/)

## 구성

| 프로그램 | 주요 작업 | 출력 |
|---|---|---|
| 현장조사 | 도면·사진 등록, 결함 위치·사진, 외관조사망도, 전경사진 | JSON, PNG, CSV, HWPX |
| 도면작성 | 스케치·실측·벽체·기둥·보·문·도면 편집 | JSON, JPG, PNG, PDF 인쇄, DXF |
| 장비조사 | 슈미트해머·탄산화·철근탐사, 조사 위치·사진 관리 | JSON, PNG, CSV, Excel |
| 기울기 | 모서리별 기울기 측정·계산·화살표 표시 | JSON, PNG, PDF, Excel |

## v142 주요 개선

- 4개 프로그램의 공통 메뉴와 패널을 일관된 간격·크기로 정돈
- 도구를 **주 작업 / 기타 도구**로 구분해 한 번에 하나의 그룹만 펼쳐 표시
- **프로젝트 공유**: 사용 기기가 지원하면 기본 공유 메뉴로 JSON 프로젝트 파일 전달, 미지원 시 파일 저장
- **프로젝트 내보내기/불러오기**는 그대로 보존. 최근 내보내기·공유 시각 안내 추가
- PWA 오프라인 캐시 갱신, 자동 배포 전 4개 프로그램 정적 회귀 검사

## v153 Android Quick Share 파일 형식

- **프로젝트 내보내기(백업):** 기존처럼 `.json`으로 저장합니다.
- **프로젝트 공유:** Android Chrome의 Web Share 파일 제한 때문에 이름이 `.sarch.txt`인 텍스트 파일로 전송합니다. 파일의 **내용은 동일한 JSON**이며 사진·도면·조사내용은 변경되지 않습니다.
- **받는 기기:** Quick Share로 받은 `.sarch.txt`를 S:ARCH의 프로젝트 불러오기에 선택하거나, 설치형 S:ARCH에 '공유'로 전달해 **새 현장으로 추가**합니다.
- 공유 메뉴가 실패하거나 50MB 이상이면 기존 `.json` 파일을 내려받아 Android 내 파일 앱에서 Quick Share로 전달하세요. 기존 데이터는 수정되지 않습니다.

## v155 현장조사 결함표시 크기 및 Android 공유 앱 등록

- 현장조사 **기타 도구 → 결함 표시 ON/OFF 옆**에서 `결함표시 크기` 슬라이더(50~200%)를 조절합니다.
- 아무 결함도 선택하지 않았으면 현재 현장의 **모든 결함번호 원형 표시와 결함 텍스트**를 일괄 조절합니다.
- 결함을 하나 선택하면 **해당 번호·텍스트만** 조절하며, `전체` 버튼은 결함 선택을 해제합니다.
- 조절값은 현재 현장 프로젝트 JSON에 저장되고 PNG 외관조사망도 내보내기에도 반영됩니다.
- Android의 공유 앱 목록에 나타나려면 **갤럭시탭 Chrome에서 S:ARCH 메인 PWA 또는 현장조사 PWA를 실제 앱으로 설치**해야 합니다. 메인에 `공유 앱 설치` 안내를 추가했습니다.
- Android Web Share Target의 시스템/Chrome 버전 제약으로 앱 선택이 안 되거나 전달된 파일이 누락되면, 메인의 `받은 현장 추가`에서 수신 `.json` 또는 `.sarch.txt` 파일을 직접 선택합니다. 설치 앱 삭제 또는 사이트 데이터 초기화는 현장 백업 이전에 절대 하지 마세요.

## v157 결함 현황표 XLSX · PDF 프로젝트 전송 · 결함표시 슬라이더

- 현장조사의 `결함 현황표 엑셀` 출력은 등록된 건물만 시트로 생성합니다. 101동만 있으면 1개, 101·102동이면 2개, 101~105동이면 5개 시트입니다.
- `부재위치 - 위치(측번호)` 열은 포함하지 않습니다. 손상 종류, 크기, 손상원인추정, 사진 수, 조치 의견을 표시합니다.
- 손상원인추정은 **결함 종류·기록을 바탕으로 작성하는 임시 초안**이며 이미지 자체를 AI로 판독한 결과는 아닙니다. 사진이 있으면 사진 확인 필요를 표시하고, 현장조사 결함 상세의 `손상원인추정`을 사용자가 직접 수정할 수 있습니다.
- `결함 표시 ON`일 때만 50~200% 크기 슬라이더가 보입니다. OFF일 때는 숨기며 설정값은 유지합니다.
- Samsung Quick Share는 텍스트 공유로 오인될 수 있는 `.sarch.txt` 대신 **유효한 PDF에 원래 JSON을 첨부한 `.sarch.pdf` 파일**을 전송합니다. 받는 갤럭시탭에서 `받은 현장 추가`를 통해 PDF를 선택하면 내장 JSON을 복구해 새 현장으로 추가할 수 있습니다.
- 기존 백업·내보내기는 계속 `.json`이고, 기존 현장 데이터는 덮어쓰지 않습니다. 갤럭시탭 두 대 사이 전송은 장치에서 최종 확인이 필요합니다.

## 시작하기

1. 위 링크에서 해당 프로그램을 연 다음 필요한 경우 홈 화면에 추가합니다.
2. 작업 현장을 생성하고 도면·사진 또는 측정 항목을 등록합니다.
3. 작업 종료 시 **프로젝트 내보내기** 또는 **프로젝트 공유**로 JSON 파일을 따로 보관합니다.
4. 다른 기기는 같은 프로그램의 **프로젝트 불러오기**로 JSON을 선택합니다.

### 자료 보관에 관해

- 프로그램은 **회원가입 없이** 사용할 수 있습니다.
- 작업자료는 기본적으로 현재 브라우저·기기의 저장공간에 보관됩니다.
- 앱 삭제, 브라우저 데이터 정리, 기기 고장 등에 대비하여 **프로젝트 JSON을 별도 보관**해야 합니다.
- 공유는 기기의 공유 기능을 사용하며, S:ARCH 서버로 업로드하지 않습니다.
- **회사 네이버 MYBOX 자동 업로드는 아직 구현되어 있지 않습니다.** 기기의 기본 공유 메뉴에서 MYBOX를 선택할 수 있는지는 기기·앱 지원 여부에 따라 달라집니다.
- 공유되는 JSON에는 현장명·사진·조사정보가 포함될 수 있으므로 회사에서 승인한 전달 경로를 사용해야 합니다.

## 개발·검증

정적 점검: `node tools/verify-sarch.mjs` — 4개 HTML 스크립트 문법, JSON 내보내기·불러오기 연결, 공유 브리지, 오프라인 캐시 및 버전을 확인합니다.

배포는 GitHub Actions와 GitHub Pages를 사용합니다. **정적 점검 통과는 실제 태블릿의 모든 조작·저장을 보장하지 않으므로**, 현장 사용 전 [기능 점검표](docs/QA-v142.md)에 따라 확인해야 합니다.
