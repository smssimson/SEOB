# S:ARCH — 건축 현장업무 플랫폼

건축 시설물의 **현장조사 · 도면작성 · 장비조사 · 기울기 조사**를 태블릿과 PC에서 수행하기 위한 웹 기반 PWA입니다.

**[S:ARCH 실행](https://smssimson.github.io/SEOB/)** · [현장조사](https://smssimson.github.io/SEOB/survey/) · [도면작성](https://smssimson.github.io/SEOB/drawing/) · [장비조사](https://smssimson.github.io/SEOB/schmidt/) · [기울기](https://smssimson.github.io/SEOB/tilt/)

## 구성

| 프로그램 | 주요 작업 | 출력 |
|---|---|---|
| 현장조사 | 도면·사진 등록, 결함 위치·사진, 외관조사망도, 전경사진 | JSON, PNG, CSV, HWPX |
| 도면작성 | 스케치·실측·벽체·기둥·보·문·도면 편집 | JSON, JPG, PNG, PDF 인쇄, DXF |
| 장비조사 | 슈미트해머·탄산화·철근탐사, 조사 위치·사진 관리 | JSON, PNG, CSV, Excel |
| 기울기 | 모서리별 기울기 측정·계산·화살표 표시 | JSON, PNG, PDF, Excel |

## v142 주요 개선

- 4개 프로그램의 공통 메뉴와 패널을 일관된 간격·크기로 정돈
- 도구를 **주 작업 / 기타 도구**로 구분해 한 번에 하나의 그룹만 펼쳐 표시
- **프로젝트 공유**: 사용 기기가 지원하면 기본 공유 메뉴로 JSON 프로젝트 파일 전달, 미지원 시 파일 저장
- **프로젝트 내보내기/불러오기**는 그대로 보존. 최근 내보내기·공유 시각 안내 추가
- PWA 오프라인 캐시 갱신, 자동 배포 전 4개 프로그램 정적 회귀 검사

## 시작하기

1. 위 링크에서 해당 프로그램을 연 다음 필요한 경우 홈 화면에 추가합니다.
2. 작업 현장을 생성하고 도면·사진 또는 측정 항목을 등록합니다.
3. 작업 종료 시 **프로젝트 내보내기** 또는 **프로젝트 공유**로 JSON 파일을 따로 보관합니다.
4. 다른 기기는 같은 프로그램의 **프로젝트 불러오기**로 JSON을 선택합니다.

### 자료 보관에 관해

- 프로그램은 **회원가입 없이** 사용할 수 있습니다.
- 작업자료는 기본적으로 현재 브라우저·기기의 저장공간에 보관됩니다.
- 앱 삭제, 브라우저 데이터 정리, 기기 고장 등에 대비하여 **프로젝트 JSON을 별도 보관**해야 합니다.
- 공유는 기기의 공유 기능을 사용하며, S:ARCH 서버로 업로드하지 않습니다.
- **회사 네이버 MYBOX 자동 업로드는 아직 구현되어 있지 않습니다.** 기기의 기본 공유 메뉴에서 MYBOX를 선택할 수 있는지는 기기·앱 지원 여부에 따라 달라집니다.
- 공유되는 JSON에는 현장명·사진·조사정보가 포함될 수 있으므로 회사에서 승인한 전달 경로를 사용해야 합니다.

## 개발·검증

정적 점검: `node tools/verify-sarch.mjs` — 4개 HTML 스크립트 문법, JSON 내보내기·불러오기 연결, 공유 브리지, 오프라인 캐시 및 버전을 확인합니다.

배포는 GitHub Actions와 GitHub Pages를 사용합니다. **정적 점검 통과는 실제 태블릿의 모든 조작·저장을 보장하지 않으므로**, 현장 사용 전 [기능 점검표](docs/QA-v142.md)에 따라 확인해야 합니다.

## 개발 원칙

기존 현장자료 보존, 점검기능의 무단 삭제 금지, 명확한 저장 상태, 복구 가능한 자료 형식, 빠르고 조용한 PWA 업데이트, 깔끔한 공통 UI를 우선합니다.
