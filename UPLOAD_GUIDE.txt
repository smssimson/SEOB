SEOB GitHub Pages 업로드
1. ZIP 압축 해제
2. GitHub smssimson/SEOB 저장소의 Add file > Upload files 선택
3. 압축 해제한 폴더 안의 index.html 파일과 drawing 폴더를 업로드 영역으로 드래그
4. Commit changes 클릭
5. Settings > Pages > Build and deployment > Deploy from a branch, Branch main, /(root) > Save
6. 배포 완료 후 https://smssimson.github.io/SEOB/ 확인
기존 README.md는 유지해도 됩니다.
