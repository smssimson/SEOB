# S:ARCH v142 현장 기능 점검표

이 점검표는 **실제 태블릿/PC에서 수행하는 수동 시험**용입니다. 수행하지 않은 시험을 완료로 표시하지 않습니다.

## 공통

- [ ] 홈에서 4개 프로그램이 정상 열림, 로고·화면 테마·뒤로가기가 정상
- [ ] 작업현장 선택·현장명 변경·현장 삭제 화면이 겹치지 않음
- [ ] 층/도면 관리의 선택·추가·이름 변경·삭제·도면 순서·회전이 정상
- [ ] 현장·도면 전환 후 기존 조사 위치·사진이 유지됨
- [ ] 현장·도면 작성 중 자동 저장 표시가 정상이고 앱 재실행 후 자료가 남음
- [ ] 주 작업/기타 도구 탭이 정상 전환되며 필수 도구가 숨지 않음
- [ ] 프로젝트 내보내기 후 **같은 앱에서** 파일을 불러와 내용이 일치함
- [ ] 프로젝트 공유에서 기본 공유 메뉴 또는 JSON 다운로드가 정상 수행됨
- [ ] 공유를 취소했을 때 불필요한 중복 다운로드가 없음
- [ ] 저장·내보내기 중 인터넷 끊김에도 기존 자료가 유지됨
- [ ] 태블릿 세로/가로 및 데스크톱 화면에서 메뉴가 겹치지 않음
- [ ] 데이터 백업 후 새 버전 업데이트에서 프로젝트가 유지됨

## 현장조사

- [ ] PDF·사진 추가, 다중 도면, 결함번호·균열·결함사진·전경사진
- [ ] 결함크기 표기(`X`, 개수만 있을 때 `EA`)가 일관됨
- [ ] 외관조사망도 PNG, 결함 CSV, HWPX 사진첩 출력
- [ ] 내보낸 JSON을 다른 기기에서 불러와 사진·번호 확인

## 도면작성

- [ ] 자유 드로잉·모서리·벽체·기둥·보·문·지우개
- [ ] 치수·회전·도면 순서·새 도면 기능
- [ ] 도면 JPG·PNG·PDF 인쇄·DXF 출력
- [ ] 프로젝트 공유 시 모든 도면과 실측 정보 보존

## 장비조사

- [ ] 슈미트해머(SH)·탄산화(PH)·철근탐사(FS) 선택형 생성
- [ ] 조사·사진·선택사항 표시·현장 전환 후 데이터 유지
- [ ] 조사 위치도·CSV·슈미트해머 Excel 출력

## 기울기

- [ ] 측정값 입력·좌/우 표시·엑셀 계산·화살표·박스 드래그
- [ ] 빨강/파랑 화살표 크기 통일 ON/OFF·슬라이더
- [ ] 미입력 측정값이 있을 때 내보내기·공유 경고
- [ ] PNG·PDF·Excel 및 백업 JSON 출력
