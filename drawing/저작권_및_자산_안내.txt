SMETRIC 자산 및 라이선스 점검 안내 (2026-10-22)

1. 화면 기본 글꼴은 돋움(Dotum)으로 지정했습니다. 폰트 파일은 포함하거나 배포하지 않습니다. 돋움이 설치되지 않은 iPad/Android 등에서는 시스템 대체 글꼴이 사용됩니다. 돋움 지정만으로 모든 사용 환경의 폰트 라이선스를 보증할 수 없습니다.
2. 현장조사의 JSZip v3.10.1은 MIT 또는 GPLv3 이중 라이선스이며, 본 배포물에는 원본 저작권 고지가 포함됩니다. 상업적 배포 시 MIT 조건을 따를 경우 라이선스 본문도 함께 제공해야 합니다. 아래 JSZip MIT 라이선스 안내를 확인하십시오.
3. 현장조사는 PDF.js 3.11.174를 외부 CDN에서 로드합니다. 해당 오픈소스의 Apache-2.0 라이선스와 관련 고지·의존성 조건은 별도 검토가 필요합니다.
4. 현장조사에 포함된 photo_album_template.hwpx, 기존 아이콘, 사용자가 업로드하는 도면·사진의 권리 관계는 본 수정으로 검증되지 않았습니다. 배포 전 권리 보유 여부를 확인하십시오.
5. 통합 앱의 SMETRIC 아이콘은 기존 프로젝트에 포함된 자산을 유지했습니다. 원본의 독창성·제3자 권리 비침해를 보증하지 않습니다.
6. 앱 UI 코드·라이브러리·이미지의 전체 권리 관계를 법적으로 확정한 것은 아닙니다. 이 파일은 법률 자문이 아닙니다.
7. 현장조사 앱의 GitHub Pages 하위 경로(/SEOB/survey/)에 맞게 매니페스트와 서비스 워커의 경로를 수정했습니다. 최초 적용 후 설치·오프라인 작동을 테스트하십시오.
